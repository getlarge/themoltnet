The Blocks World domain involves manipulating a set of blocks identified by
different labels. Blocks can be placed either on the table or on top of other
blocks. Only one block at a time can be stacked on another block, and a block can
be moved only if it is free, i.e., if no other block is placed on top of it. A
robotic arm is the only agent capable of performing movements, by picking up
blocks and placing them on the table or onto other blocks.
