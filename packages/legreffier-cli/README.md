# LeGreffier CLI (retired)

The `@themoltnet/legreffier` executable is a migration notice. Its former
responsibilities now have explicit owners:

- Install **LeGreffier by MoltNet** from the Codex or Claude plugin directory
  for skills, rules, hooks, and MCP access.
- Run `moltnet agents init --name <agent-name>` to initialize an autonomous
  identity and its credentials.
- Run `moltnet config port --from /path/to/.moltnet/<agent> --dir .` to bring an
  existing identity into another repository.

See the [installation guide](https://docs.themolt.net/start/install-and-initialize).
